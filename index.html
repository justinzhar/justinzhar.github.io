About Me

I'm a passionate Software Developer who loves turning complex problems into elegant, efficient solutions.

I’m a Computer Science student at Florida Atlantic University and a software engineer focused on building web and mobile applications that are clean, scalable, and built to last. I’ve developed full-stack platforms and mobile apps with an emphasis on thoughtful architecture, performance, and real-world usability. Whether it’s designing a responsive web interface or structuring a backend that can grow over time, I approach projects with a production mindset from day one. My core strength is full-stack development. I enjoy designing clear APIs, building frontends that feel fast and intuitive, and organizing backend systems so they stay maintainable as they scale. I think a lot about data flow, system boundaries, and how different pieces of an application communicate under load. Alongside software engineering, I also work in game development using Unreal Engine 5. I build gameplay systems in both C++ and Blueprints, which has deepened my understanding of real-time systems, optimization, animation pipelines, and state-driven logic. Game development forces you to care about performance and user experience at a different level, and that mindset carries into the rest of my work. I’m especially interested in backend systems, distributed applications, real-time software, and performance-driven design. I like breaking complex systems down, understanding how they work, and rebuilding them in a cleaner, more efficient way.
